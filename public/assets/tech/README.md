Put your local technology PNG/SVG files in this folder.

Examples:
- python.png
- c.png
- go.png
- javascript.png
- java.png
- typescript.png
- html5.png
- css3.png
- bash.png
- jinja.png
- gitlab.png

The app reads from /assets/tech/<filename> first.
If a file is missing, it falls back to a CDN icon.
